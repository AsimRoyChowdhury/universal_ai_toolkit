# Contributing to Universal AI Toolkit

Thank you for your interest in contributing! We love community input.

## How to Contribute
1.  **Fork** the repo on GitHub.
2.  **Clone** the project to your own machine.
3.  **Create a Branch** for your feature (`git checkout -b feature/amazing-feature`).
4.  **Commit** changes to your own branch.
5.  **Push** your work back up to your fork.
6.  **Submit a Pull Request** so that we can review your changes.

## Coding Guidelines
* **Linting:** We use the strict `flutter_lints` package. Run `flutter analyze` before pushing.
* **Formatting:** Run `dart format .` to ensure your code looks standard.
* **Comments:** Public classes and methods must have documentation comments (`///`).

## Reporting Bugs
Please use the "Bug Report" issue template when reporting bugs.
